Update firmware and web interface

Keeps Wi-Fi settings, uploaded ebooks, and reading progress. Only the active firmware and web interface partitions are written.

Open this page in desktop Chrome or Edge to use USB flashing.

USB flashing requires this secure GitHub Pages address.

Do not check "Erase device". The installer will ask whether to erase the chip before writing. Leave that box unchecked. Answering yes wipes the entire flash first — WiFi settings, your ebook library, everything — and this update only rewrites firmware and the web UI afterwards, so nothing else gets restored.

Before you start

Three quick steps

  1. 1
    Connect USB

    Use a data-capable USB cable and switch Book32 on.

  2. 2
    Choose the device

    Select the XIAO ESP32-S3 serial port when the browser asks.

  3. 3
    Let it finish

    Keep the cable connected until installation completes and Book32 restarts.

Device does not appear?

Hold the BOOT button, tap RESET, then release BOOT and try connecting again.

New or blank hardware?

This installer only updates a Book32 that is already running. To flash a blank XIAO ESP32-S3 for the first time, follow the PlatformIO instructions in the README.
